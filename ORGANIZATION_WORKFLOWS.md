# Organization Workflows

## Onboard / maintain organization profile

1. System administrator opens **Organization Profile**.
2. Updates general, contact, location, and preference fields.
3. Uploads/replaces logo (image ≤ 2MB).
4. Saves; audit log records changes.

## Configure structure

1. Create geographic types (optional) then geographic units top-down (country → …).
2. Create departments (optional parent for hierarchy).
3. Create offices (department optional; may link geographic unit).
4. Create facility types, then facilities (office optional; coordinates validated).

## Assign sectors

1. Open **Sectors**.
2. Select catalogue sectors for the organization.
3. Save via sector sync endpoint.

## Users & teams

1. Invite/create user with temporary password and roles.
2. Activate/deactivate membership as needed.
3. Create team, assign leader/department/office, sync members.

## Reporting calendar

1. Create calendar with frequency.
2. Add periods with start/end dates.
3. Open period for data collection window; close when complete.

## Settings

1. Open **Organization Settings**.
2. Set timezone, language, currency, date format (and other keys).
3. Save key/value settings for the active organization only.
