# Angular Material Components Used

Studied against https://material.angular.dev/components/categories  
Installed: `@angular/material` / `@angular/cdk` **22.3.0** (Angular **22.2**)

## Navigation
- `MatSidenav` / `MatSidenavContainer` / `MatSidenavContent`
- `MatToolbar`
- `MatMenu`
- `MatNavList` / `MatListItem`

## Layout
- `MatCard`
- `MatDivider`
- `MatExpansionPanel` module imported for future expandable groups (nav currently uses grouped lists)

## Data table
- `MatTable` (recent activities)

## Form controls
- `MatFormField`, `MatInput`, `MatSelect`, `MatCheckbox`

## Buttons & indicators
- `MatButton`, `MatIconButton`
- `MatIcon`
- `MatBadge`
- `MatChip` / `MatChipSet`
- `MatProgressSpinner`

## Popups & modals
- `MatSnackBar`
- `MatTooltip`
- `MatMenu` (profile, org switcher, notifications)

## Charts (companion)
- `ng2-charts` + `chart.js` for project status doughnut

  - Primary `#142B45`
  - Secondary `#117C78`
  - Accent `#D5AD55`
