# Lessons Learned — Design

## Attributes
Reference, title, source, project/programme/evaluation/feedback links, context, challenge, what worked / did not, recommendation, responsible person, action required.

## Workflow
`identified/documented` → `under_review` → `approved` → `action_assigned` → `applied`

## Integration
- `lesson_links` morph to strategic plans, AWPs, projects, results, indicators, evaluations
- `learning_actions` track whether the organization applied the lesson
